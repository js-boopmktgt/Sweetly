# Sweetly

Tienda en línea de Sweetly, postres a domicilio en Guatemala. Sitio estático: catálogo, carrito, envío por zona y pedido con pago por transferencia.

## Cómo editar

Todo lo configurable está al inicio del bloque `<script>` de `index.html`:

- `CONFIG.whatsapp`: número de pedidos con código de país, sin signos.
- `CONFIG.zonas`: zonas de entrega y costo de envío de cada una.
- `CONFIG.banco`: datos para la transferencia.
- `PRODUCTOS`: nombre, categoría y precio de cada postre.
